# 제품 요구사항

- 상태: Draft
- 마지막 검토일: 2026-09-08

## 문제 정의

개인 학습자는 공부한 내용을 빠르게 기록하면서도, 시간이 지난 뒤 날짜와 주제를 기준으로 다시 찾을 수 있어야 한다.

## 사용자 시나리오

> 학습 기록 작성자로서 Markdown 파일 하나만 추가해 새 글을 게시하고 싶다. 그래야 사이트 관리보다 공부와 기록에 집중할 수 있다.

> 방문자로서 최근 글과 전체 기록을 빠르게 둘러보고 싶다. 그래야 관심 있는 학습 내용을 쉽게 찾을 수 있다.

## 기능 요구사항

| ID | 요구사항 | 우선순위 | 수용 기준 |
|---|---|---|---|
| FR-001 | 홈에 최신 글을 날짜순으로 표시한다 | Must | 새 게시물이 가장 위에 제목·분류·날짜와 함께 표시됨 |
| FR-002 | 전체 게시물 목록을 제공한다 | Must | ARCHIVE 메뉴에서 모든 게시물에 접근 가능 |
| FR-003 | Markdown 게시물을 HTML로 생성한다 | Must | 유효한 front matter를 가진 글이 고유 주소로 빌드됨 |
| FR-004 | 사이트 소개 페이지를 제공한다 | Must | PROFILE 메뉴로 목적과 학습 범위를 확인 가능 |
| FR-005 | RSS 피드를 제공한다 | Should | `/feed.xml`에서 최신 글을 확인 가능 |

## 비기능 요구사항

| ID | 영역 | 기준 |
|---|---|---|
| NFR-001 | 호환성 | GitHub Pages의 Jekyll 빌드 환경에서 성공적으로 생성 |
| NFR-002 | 반응형 | 320px 이상 화면에서 가로 페이지 스크롤 없이 사용 가능 |
| NFR-003 | 접근성 | 키보드 탐색, 본문 바로가기, 의미 있는 제목 구조 제공 |
| NFR-004 | 성능 | 외부 런타임과 웹폰트 없이 핵심 콘텐츠 제공 |
| NFR-005 | 보안 | 비밀값과 개인정보를 저장하거나 입력받지 않음 |

## 범위 제외

- 댓글, 로그인, 검색 서버, 관리자 화면
- 웹에서 직접 글을 저장하는 기능
- 방문 통계와 제3자 광고
